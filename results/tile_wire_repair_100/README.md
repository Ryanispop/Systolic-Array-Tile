# Sky130 MAC tile implementation snapshot

Source run: `runs/tile_wire_repair_100`, completed October 1, 2026 with
LibreLane `3.1.0.dev1`, Classic flow, `sky130A` / `sky130_fd_sc_hd`.
The top is `mac_tile`, with `N=2`, `DATA_W=8`, and `ACC_W=32`.
The die is 400 x 400 um and the clock target is 30 ns.

## Status and limitations

DRC (Magic and KLayout), LVS, antenna, and GDS XOR checks pass. Setup and hold
pass across the analyzed corners, with worst slacks of +3.496362 ns and
+0.109347 ns. Worst-corner slew violations are zero.

Two capacitance violations remain at `max_ss_100C_1v60`:

| Driver pin | Limit (fF) | Actual (fF) | Excess (fF) |
| --- | ---: | ---: | ---: |
| `_4916_/Y` | 42.124 | 42.957 | 0.833 |
| `_3500_/Y` | 26.560 | 27.061 | 0.501 |

These values come from the source run's
`57-openroad-stapostpnr/max_ss_100C_1v60/checks.rpt`.
There are also 21 clock-tree fanout violations. The all-corner capacitance
checker fails the flow; generation of GDS does not indicate complete electrical
closure. This is a core block without pads, not a standalone fabricated chip.
IO delays and loads are the initial assumptions documented in the root README.

Violation totals in the root README use the worst-corner aggregate metrics;
they are not sums over corners, which can count the same pin repeatedly.

## Reproduction

From the repository root, with the installed Sky130 PDK:

```sh
librelane --manual-pdk --pdk-root /foss/pdks \
    --pdk sky130A --scl sky130_fd_sc_hd --flow Classic -j 4 \
    -c DESIGN_REPAIR_MAX_WIRE_LENGTH=100 \
    -c GRT_DESIGN_REPAIR_MAX_WIRE_LENGTH=100 \
    --run-tag tile_wire_repair_100_repro config.json
```

The tested wire-length settings are also saved in the root `config.json`.
They retain the 30% GRT slew/capacitance margins, slow default corner, and
`sky130_fd_sc_hd__or2_0` exclusion from the preceding experiment.
Tool/PDK revisions and future configuration changes may change the results.
